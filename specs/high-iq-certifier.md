# high-iq-certifier

**One-line:** The origin story. Commits `still high IQ` on a loop, forever.

**Difficulty:** 🟢 *trivial*

**What it secretly teaches:** The absolute minimum viable fire-and-forget harness: a scheduled job, a file append, a git commit, and a push. If you can make this run for 30 days without human intervention, you understand the shape of the whole project.

**Output per tick:** Append one line to `still-high-iq.txt`:

```
still high IQ — 2026-07-06T12:34:56Z
```

**Tick cadence:** Hourly or daily. Daily is funnier; hourly is more impressive.

**Commit message convention:** `still high IQ`

**README:** One sentence: "Quality is measured in quantity."

**Why this is the founder repo:** It proves the harness works before any real algorithm is added. It is the shitpost that justifies the rest. The CEO who said you only know buzzwords now has a GitHub profile full of green squares caused by a single, unkillable, self-referential statement.

**Extensions:**
- Vary the line with a rotating set of phrases ("still high IQ", "still 10x", "still Agile", etc.).
- Add a badge showing the current streak.
- Make it tweet/toot the line on a social account you don't care about.
